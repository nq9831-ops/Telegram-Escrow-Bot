# 手把手部署（大白话版）

> 这份文档是给**没搞过服务器**的人看的。你不需要懂任何专业词——我会一步一步告诉你
> **点哪个按钮、填什么、填完看到什么算成功**。照做就行，遇到跟文档不一样的地方，
> 先看第 12 步的「出错了怎么办」。
>
> 全部做完大约需要 1–2 小时（大部分时间在等软件安装）。

---

## 开始之前：你需要准备这 6 样东西

| 要准备的 | 它是干嘛的 | 去哪弄 |
|---|---|---|
| 1 台服务器 | 一台一直开着的电脑，程序住在里面 | 阿里云/腾讯云等随便买个最便宜的（2 核 4G 就行） |
| 1 个域名 | 别人访问你系统的网址 | 买服务器的地方通常也能买（几十块一年） |
| 1 个 Telegram 机器人 | 用户跟系统对话的入口 | 在 Telegram 里找 **@BotFather** 免费申请（第 4 步教你） |
| 1 个 TON 钱包 | 用来「掌管系统升级」的钱包（像公章，**助记词就是公章钥匙，绝不能丢也不能给别人**） | 手机装个 TON 钱包 App，新建一个（第 5 步教你） |
| 部署包（本压缩包） | 程序本体 + 说明书 | 你已经在看它了 |
| 30 分钟耐心 | 装软件要等 | —— |

⚠️ **最重要的一句话**：整套系统里**只有「钱包助记词」丢了无法补救**——创建钱包后，
把 24 个单词**用笔抄在纸上**，抄两份放两个地方。千万别只存手机截图。

---

## 第 1 步：服务器装宝塔面板（约 10 分钟）

宝塔面板 = 一个网页版的控制台，装完之后，管服务器就像管手机一样点按钮。

1. 打开宝塔官网 **bt.cn**，在「下载安装」页面**选择你的服务器系统**，复制那行**安装命令**；
2. 在你的服务器管理后台（云厂商的控制台里）找到「远程登录/终端」，粘进去回车，等它装完；
3. 装完屏幕会给你一个**面板地址 + 账号 + 密码**——抄下来。用浏览器打开那个地址，登录。

✅ **成功长这样**：浏览器里出现宝塔的网页控制台，能用账号密码登录进去。

> 顺便做两件事：云服务器后台的「安全组」里放行 **80、443** 端口（不然外网访问不了）；
> 宝塔装好后如果提示「推荐安装套件」，随便选一个都行（我们下一步自己装需要的）。

---

## 第 2 步：在宝塔里装 4 个软件（约 20 分钟，等它装）

打开宝塔左边的 **软件商店**（就像手机的应用商店）：

| 要装的 | 搜什么 | 选哪个 |
|---|---|---|
| 1. Nginx | `nginx` | 任意稳定版，点安装 |
| 2. MySQL 8 | `mysql` | **8.x 版本**，点安装 |
| 3. Java 项目管理器 | `java` | 「Java 项目管理器」，点安装 |
| 4. JDK 21 | （见下） | 装完 Java 项目管理器后，进 **网站 → Java 项目 → JDK 管理**，找到 **jdk-21** 点安装 |

✅ **成功长这样**：软件商店里这 4 个都显示「已安装」。

> 为什么必须是 **21**？因为这个程序（的 jar 文件）只认 21 这个版本，装错版本会闪退，
> 而且报错你多半看不懂（叫 `UnsupportedClassVersionError`）。认准 **21** 就行。

---

## 第 3 步：建一个数据库（约 2 分钟）

数据库 = 系统记账用的「仓库」，订单、账本都放里面。

1. 宝塔左边点 **数据库** → **添加数据库**；
2. 三个空这样填：
   - 数据库名：`tgg_escrow`（照抄）
   - 用户名：`tgg`（照抄）
   - 密码：**点那个「随机」按钮**，生成一串乱码——然后**把它抄下来**（第 6 步要用）；
3. 权限选 **本地服务器**（别选「所有人」）；
4. 其他不用动，点提交。

✅ **成功长这样**：数据库列表里出现一行 `tgg_escrow`。

> 提示：表格不用你建——程序第一次启动会自己把要用的表格全部建好。

---

## 第 4 步：在 Telegram 申请机器人（约 5 分钟）

1. 打开 Telegram，在搜索框搜 **@BotFather**（官方发机器人的号，名字带蓝色认证）；
2. 点进去，发一条 `/newbot`；
3. 它会问你「给机器人起个名」——随便起（显示给人看的，比如「担保交易」）；
4. 再问你「起个用户名」——必须是英文+结尾带 `bot`（比如 `myescrow_bot`），被占用了就换一个；
5. 成功后它会发给你一串 **Token**（长这样：`123456789:AA开头一串字符`）——**把这串完整抄下来**（第 6 步要用）。
6. 再发一条 `/setcommands`，选你刚建的机器人，然后粘贴这行发出去：
   ```
   escrow - 托管交易（下单/托管/交付/放款/退款/争议/查询）
   ```
   （这样用户输入框旁边会弹出命令提示）

✅ **成功长这样**：你在 Telegram 里搜索你起的用户名（如 `@myescrow_bot`），能找到它。

---

## 第 5 步：准备治理钱包（约 10 分钟，**助记词是命根子**）

这个钱包专门用来「盖章」（将来系统要升级合约时用它签名）。**不是**用来收用户钱的。

1. 手机装一个支持新版协议（V5）的 TON 钱包 App（应用商店搜 `Tonkeeper` 或类似都行）；
2. **新建一个钱包**（不要用你存大钱的老钱包）；
3. 创建时会给你 **24 个英文单词**——**立刻用笔抄在纸上，抄两份，放两个地方**；
   （如果 App 问要不要「云端备份」——那等于把单词交给第三方服务器保管，自己权衡）；
4. 在钱包 App 里找到它的「地址」（一串 `EQ` 或 `kQ` 开头的），抄下来；
5. 往这个钱包里转 3–5 个 TON（将来升级要用的手续费，先放着）。

> **「公钥」和「walletId」去哪拿？** 大部分手机钱包**不显示**这两样——别纠结、更别猜：
> 等第 6 步把 `env.sh` 建好之后，用部署包里自带的小工具（`wallet-selfcheck`）一跑，
> 地址、公钥、walletId 会一起算出来，还会**帮你检查填得对不对**
> （见第 6 步末尾的「💡 钱包自检 2 分钟」）。

✅ **成功长这样**：你手上有一张抄好的纸（**24 个单词**）+ 钱包 App 里能看到地址。

---

## 第 6 步：把程序文件和配置放上服务器（约 15 分钟）

要放的就 **2 个文件**：

- `tgg-app.jar` —— 程序本体（部署包 `app/` 文件夹里）
- `env.sh` —— 一张「填空题」纸，程序每次启动都会照着读（第 7 步教你怎么填）

**操作**：

1. 宝塔左边点 **文件** → 进到 `/www/wwwroot/` → 新建一个文件夹，名字 `tgg`；
2. 进入 `tgg` 文件夹，点**上传**，把 `tgg-app.jar` 传上去；
3. 打开部署包里 `config/env.example.sh`（这是填空题的模板），**只填下面这几个空**，其他都不用动：

| 填空题（=号后面） | 填什么 |
|---|---|
| `TGG_DB_PASSWORD=` | 第 3 步抄的数据库密码 |
| `TELEGRAM_BOT_TOKEN=` | 第 4 步抄的机器人 Token |
| `TELEGRAM_BOT_USERNAME=` | 你的机器人用户名（不要带 @） |
| `TGG_WEBAPP_URL=` | `https://你的域名`（域名先把第 8 步做完再回来确认） |
| `TGG_ADMIN_USERNAME=` | 给自己起个管理员名（随便，如 `admin`） |
| `TGG_ADMIN_PASSWORD=` | 管理员密码——**起个长的乱的**（这个密码保护所有管理功能） |
| `TGG_CHAIN_UPGRADE_WALLET_MNEMONIC=` | 第 5 步抄的 **24 个单词**（原样，空格隔开） |
| `TGG_FEDERATION_ADDRESS=` | 第 5 步抄的钱包地址 |
| `TGG_FEDERATION_PUBLIC_KEY=` | 第 5 步抄的公钥 |

   > 还有个 `TGG_CHAIN_TESTNET=` 在模板里默认是 `true`（测试网）——**第一次部署保持 true 不动**，
   > 等全部试通了、要正式上线，再改成 `false` 并重启（第 11 步最后会说）。

4. 填好后，在宝塔 **文件** 页面点开 `tgg` 文件夹，**新建文件**，名字叫 `env.sh`，
   用在线编辑器把你填好的内容**整个粘进去**、保存；
5. 再到宝塔的 **终端**（左边菜单里有）敲这一行回车（给这张纸加锁，只有服务器管理员能看）：
   ```bash
   chmod 600 /www/wwwroot/tgg/env.sh
   ```

✅ **成功长这样**：`/www/wwwroot/tgg/` 里躺着两个文件 `tgg-app.jar` 和 `env.sh`。

---

### 💡 钱包自检 2 分钟（强烈建议——把第 5 步的钱包信息补齐并核对）

现在 `env.sh` 里已经有你抄的助记词了，用它算出「地址、公钥、walletId」并检查对不对。
宝塔【终端】里**一行一行**照抄（每行回车）：

```bash
cd /www/wwwroot/tgg
unzip -q -o tgg-app.jar 'BOOT-INF/*' -d /tmp/tgg-cls
set -a; . ./env.sh; set +a
java -cp "/tmp/tgg-cls/BOOT-INF/classes:/tmp/tgg-cls/BOOT-INF/lib/*" scripts/wallet-selfcheck.java
```

屏幕上会列出（照着填回 `env.sh`）：
- **地址**（EQ/kQ 开头）→ 填回 `TGG_FEDERATION_ADDRESS=`
- **公钥**（base64 一串）→ 填回 `TGG_FEDERATION_PUBLIC_KEY=`
- **walletId** → 一般就是网络默认值，不用管；万一不对工具会提醒你

**再核对一次（30 秒）**：把手机钱包里显示的地址，复制进下面这行（替换引号里的内容）再跑：

```bash
TGG_EXPECTED_WALLET_ADDRESS="手机里复制的地址" java -cp "/tmp/tgg-cls/BOOT-INF/classes:/tmp/tgg-cls/BOOT-INF/lib/*" scripts/wallet-selfcheck.java
```

- 出现 **✅ 对拍一致** → 完美，继续第 7 步；
- 出现 **⚠️ 不一致** → 别慌：工具会**自动帮你找到正确的 walletId** 并告诉你填哪；照做后再跑一遍即可。

> 为什么非要做：这三个信息只要有一个对不上，将来「升级合约」的签名会发不出去，而且报错看不懂——
> 现在花两分钟，省掉以后的抓狂。

---

## 第 7 步：让宝塔把程序跑起来（约 5 分钟）

1. 宝塔左边点 **网站** → 顶部选 **Java 项目** → 点 **添加 Java 项目**；
2. 表格这样填（没提到的就保持默认）：

| 格子 | 填什么 |
|---|---|
| 项目名 | `tgg-bot` |
| 项目路径 | `/www/wwwroot/tgg` |
| jar 路径 | `/www/wwwroot/tgg/tgg-app.jar` |
| JDK | 选 **jdk-21**（第 2 步装的） |
| 端口 | `8080` |
| 运行用户 | `root` |
| **启动命令** | **清空掉**自动生成的，换上下面这一整行（照抄）： |

```
bash -c 'set -a; . /www/wwwroot/tgg/env.sh; set +a; exec /www/server/java/jdk-21.0.2/bin/java -Xmx768m -Xms256m -jar /www/wwwroot/tgg/tgg-app.jar --server.port=8080'
```

3. 点确定/保存。项目会自动开始跑。

> **那行命令是干嘛的？** 大白话：让程序**先读**你那张 `env.sh` 填空题，再开跑。
> 这样你的密码、Token、助记词只存在服务器文件里，**不会出现在宝塔的页面上**。

✅ **成功长这样（耐心等 1–2 分钟）**：项目列表里 `tgg-bot` 状态是**运行中**；
点开它的**日志**，滚到最底下能看到一行 `Started EscrowBotApplication`。
（如果 2 分钟后还是「未启动」——去第 12 步对照排查。）

---

## 第 8 步：绑域名 + 加反向代理（**最关键的两步，漏一步=打不开**）

先用大白话解释一下，不然容易漏：

> 绑域名 = 给你的系统**挂了个门牌号**；
> 加反向代理 = 把**门牌号接到屋里**。
> 只挂牌子不接电线，访客来了只能吃闭门羹（网页显示 **403**）——这是新手最容易踩的坑。

**第一步：绑域名**
- 网站 → Java 项目 → 你的 `tgg-bot` → 域名管理 → 添加：填你的域名。保存。

**第二步：加反向代理（真正的接线）**
- 宝塔左边菜单 → **网站** → 选到 **反向代理** 这一栏 → **添加反向代理**：
  - 代理名称：`tgg`
  - 目标 URL：`http://127.0.0.1:8080`（照抄，一个字都别改）
  - 发送域名：`$http_host`（默认就是，别动）
  - 域名：你的域名
- 保存。

✅ **验证接线成功**：浏览器打开 `http://你的域名/miniapp/index.html`——能显示出页面就不是 403 了。
（如果还是 403：回宝塔 终端 敲 `grep -r "proxy_pass" /www/server/panel/vhost/nginx/`，
看看有没有一行带 `8080`——没有就是反向代理没加上，回第二步重做。）

---

## 第 9 步：开启 HTTPS（约 3 分钟，Telegram 强制要求）

Mini App 必须在 https 下才能打开，好在宝塔一键就能签证书：

1. 宝塔 → **网站** → 找到你的域名那个站点 → **SSL**；
2. 选 **Let's Encrypt** → 勾上你的域名 → 点申请（等 1 分钟）；
3. 申请成功后，把「**强制 HTTPS**」的开关**打开**。

✅ **成功长这样**：浏览器打开 `https://你的域名/miniapp/index.html`，地址栏有小锁头。

> 然后回第 6 步：把 `env.sh` 里的 `TGG_WEBAPP_URL` 确认填的是 `https://你的域名`，
> 并到 Java 项目点一下**重启**（让程序读到最新配置）。

---

## 第 10 步：检查一下都活了没（3 分钟）

**① 程序活着**：Java 项目状态「运行中」；
**② 网页活着**：手机/电脑浏览器打开 `https://你的域名/miniapp/index.html` 有页面；
**③ 机器人活着**：Telegram 里私聊你的机器人，发一条 `/escrow`——**它回你一大段用法说明**。

三条都过 = **部署成功** 🎉。接下来做两个自动化小任务就齐活了。

---

## 第 11 步：加两个自动任务（最后一步，约 10 分钟）

这两个任务就像「定时闹钟」，让系统自己照顾自己：

**任务一：对账心跳（每 10 分钟自动检查链上资金状态，有异常会告警）**

1. 把部署包 `scripts/heartbeat.sh` 传到 `/www/wwwroot/tgg/`（和程序放一起）；
2. 宝塔 → **计划任务** → 添加任务：
   - 任务类型：**Shell 脚本**；任务名称：`tgg-heartbeat`；执行周期：**10 分钟**；
   - 脚本内容（照抄一整行）：
   ```bash
   set -a; . /www/wwwroot/tgg/env.sh; set +a; TGG_ADMIN_USER="${TGG_ADMIN_USERNAME}" TGG_ADMIN_PASS="${TGG_ADMIN_PASSWORD}" bash /www/wwwroot/tgg/heartbeat.sh >> /www/wwwroot/tgg/heartbeat.log 2>&1
   ```
3. 保存后**点一次「执行」手动跑一遍**——去「日志」里看，出现像
   `{"ok":true,"mode":"batch","total":..,"dangers":[]}` 这样的回执就是成功。

**任务二：每天自动备份数据库（凌晨 4 点半）**

1. 把 `scripts/backup-db.sh` 传到 `/www/wwwroot/tgg/`；
2. 打开它开头几行注释，把你第 3 步的数据库信息填进指定位置（注释会告诉你填哪）；
3. 宝塔 → 计划任务 → 添加：Shell 脚本；周期「每天 4:30」；脚本内容：
   ```bash
   cd /www/wwwroot/tgg && ./backup-db.sh >> /www/wwwroot/tgg/backup.log 2>&1
   ```

✅ **成功长这样**：计划任务列表里两条任务都在，且手动执行过没报错。

> **正式上线时**：把 `env.sh` 里的 `TGG_CHAIN_TESTNET` 改成 `false`（主网），
> 重启 Java 项目。改之前先按部署包里的「使用说明」在测试网把下单→托管→交付→放款走一遍。

## 第 12 步：出错了怎么办（对着症状查）

| 你看到的 | 多半是 | 怎么办 |
|---|---|---|
| 打开域名显示 **403** | **忘了加反向代理**（第 8 步第二步） | 回去把反向代理加上（目标 `http://127.0.0.1:8080`） |
| 打开域名显示 **502** | 程序没起来 | 看 Java 项目日志最底下的报错；对照下表 |
| 日志里 `Communications link failure` | 数据库连不上 | 检查 env.sh 里数据库密码是不是抄错；数据库是不是在运行 |
| 日志里 `UnsupportedClassVersionError` | JDK 版本错了 | Java 项目里把 JDK 改成 **jdk-21** 重启 |
| 日志里 `Address already in use` | 8080 端口被别的程序占了 | 宝塔 终端 `ss -ltn \| grep 8080` 找到占用者处理，或给项目换个端口（换完记得反向代理里也跟着换） |
| 日志里 `Flyway ... validate failed` | 数据库迁移文件被改动过 | 用原版部署包重传程序，别手工改数据库 |
| 机器人不回消息 | Token 填错了 或 服务器连不上 Telegram | env.sh 里 Token 再核对一遍；等两分钟重启项目 |
| 打开白屏/一直转圈 | 没开 HTTPS 或域名没解析对 | 回第 9 步；域名解析检查（域名商后台把域名指向服务器 IP） |
| 什么都对了重启后却打不开 | 重启要等 1–2 分钟 | 程序启动慢（约 80 秒）是正常的，泡杯茶再刷新 |

> 还搞不定？把「Java 项目 → 日志」最底下的 30 行发出来求助——90% 的问题看日志最后几行就能定位。

| 文档里的词 | 大白话 |
|---|---|

| 端口（8080） | 程序在服务器上的「门牌号」 |
| 反向代理 | 把域名这扇大门，接到 8080 这扇小门上（接线员） |
| 环境变量 / env.sh | 程序启动前要读的「填空题」（密码、密钥都放这） |
| 数据库 | 系统记账的大仓库 |
| 迁移（Flyway） | 程序自己建表格、改表格的过程（全自动，不用管） |
| Token | 机器人的「身份证密码」 |
| 助记词 | 钱包的「钥匙串」，丢了就再也打不开这个钱包 |
| 测试网 / 主网 | 练习场 / 正式场（练习场里的币是假的，随便造） |
| 计划任务 | 定时闹钟（让系统定时自己干活） |
